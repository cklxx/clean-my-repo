# Slop Pattern Catalog

Extended reference. `prompt.md` has the core rules; this lists more patterns.

## Filler openers

Delete. Start with the content.

| Slop | Replace with |
|------|--------------|
| It's worth noting that X | X |
| It's important to note/understand that X | X |
| In today's [world/landscape/era], X | X |
| When it comes to X, Y | Y |
| It goes without saying that X | X |
| Needless to say, X | X |
| Suffice it to say, X | X |
| Here's the thing: X / Here's what/why X | X |
| The truth is, X / Let me be clear: X | X |
| It's no secret that X | X |
| At the end of the day, X | X |
| The fact of the matter is X | X |
| The reality is X | X |
| The bottom line is X | X |

## Hedging

Cut unless the uncertainty is the point.

| Slop | Replace with |
|------|--------------|
| may / might / could | is / does / can |
| can be considered | is |
| tends to / is often | does / is |
| somewhat / rather / quite / fairly / relatively | cut |
| could potentially | could OR potentially (not both) |

## Formulaic transitions

Replace with a period.

Furthermore, Moreover, Additionally, In addition, Consequently, Therefore,
Thus, Hence, sentence-initial However, On the other hand, As a result.

## Redundant summaries

Delete. In conclusion, To sum up, In summary, Overall, All in all, As we've
seen, The future looks bright, Only time will tell.

## Sentence-structure tells

**Binary contrast.** "Not X, but Y" / "It's not X — it's Y" / "Not just X, but Y"
→ state Y.

**Cleft sentences.** "It is X that Y", "What X does is Y" → rewrite directly.

**Significance inflation.** "Marking a pivotal moment in the evolution of...",
"a watershed moment" → state what happened.

**False agency.** Inanimate objects doing human actions → name the person or
use "you". "The decision emerges" → "someone decides". "People tend to..." →
"You...".

## Chatbot artifacts

Delete. "I hope this helps!", "Let me know if you have any questions", "Great
question!", "I'd be happy to help!", "Absolutely!", "Certainly!", "Of course!",
"Does that make sense?", "Thank you for your patience", "As of my last
training data...", "Let me think...", "You're asking about X...".

## Emoji and decoration

Remove unless functional. 🚀✨🔥💡⭐. Excessive bold (1-2 per section max).
Curly quotes in plain text/code → straight quotes.

## Structural bloat

- Unnecessary section headers (one short paragraph → merge)
- 2-3 short bullet items → one sentence
- "Key takeaways" sections that repeat content → delete
